1. Linear Workflows

A linear workflow is a sequence of nodes executed one after another in a fixed order. Each node performs a task and passes its output to the next node until the workflow is completed.

2. Conditional Edges

Conditional edges allow the workflow to choose different paths based on specific conditions. 

3. Routing Logic

Routing logic is the decision-making mechanism used to determine the next node in a workflow. It analyzes the current state or input and directs the execution flow to the appropriate node.

4. State-Based Decisions

State-based decisions are decisions made using values stored in the workflow's state. The system examines state variables and chooses the next action or route accordingly.
